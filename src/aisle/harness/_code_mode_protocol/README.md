This package carries the Code Mode gRPC schema from OpenAI Codex
`rust-v0.153.4`, `codex-rs/code-mode-protocol/src/grpc/codex.code_mode.v1.proto`.
Upstream: https://github.com/openai/codex/tree/rust-v0.153.4/codex-rs/code-mode-protocol

The upstream schema is Apache-2.0 licensed; see LICENSE. `descriptor.pb` is the
serialized file descriptor generated by protoc from that schema with the source
filename `codex_code_mode.proto`. Runtime message classes use protobuf's public
message factory; AISLE does not vendor generated client/server implementations.

The schema describes a transport, not verified complete frontend coverage.
